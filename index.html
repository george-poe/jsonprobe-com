Seven tools, one page each, and all of it runs in your browser tab. Paste JSON and get it back consistently indented; get the exact line and column of the first syntax error; walk a large document as a collapsible tree; query it with JSONPath; diff two documents by structure rather than by text; validate against a JSON Schema.

There is no upload step to disable, because there is no upload — parsing and formatting happen in a Web Worker inside the page, and no request this page makes carries your document. That is also why a 100 MB file does not freeze the tab: the work is off the main thread, so the worst frame stayed at 53.5 fps and the average was 63.7 while the worker crunched. The performance figures on each page were measured in Chrome 152, and the code that produced them ships alongside the page so you can re-run it.

Everything is free, with no account and no rate limit. If the file is already on disk and you have a terminal, python -m json.tool is faster and gives you an exit code — these pages are for clipboard-sized problems, for looking at structure instead of reading text, and for the case where a syntax error is somewhere in forty thousand lines.

Every tool on this site runs inside your browser tab, and nothing you paste is sent anywhere. The one outbound request the code can make is the optional schema-by-URL fetch on the Schema tab: it sends the URL you typed, never your document.
